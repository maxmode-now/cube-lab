Pick a cube size and a method. Each page is a written recipe with diagrams and algorithms — the same steps you can practise in Cube Lab.

Where to start

New to cubes? Open the 3×3 beginner method, or the shorter 2×2 if you only have a Pocket Cube. Skim cube notation if the letter codes look unfamiliar.

Already solve a 3×3? Choose CFOP for the common speed path, or Roux for blocks and M-slice flow. Big cubes use reduction: 4×4 or 5×5.

Speed methods and case libraries come after that first solve. F2L, OLL, and PLL pages assume you already know the CFOP overview.

FAQ

Which guide should I start with?

If you have a 3×3, use the 3×3 beginner method. If you only have a Pocket Cube, use the 2×2 beginner page. Learn notation first if the letter codes look unfamiliar.

When should I learn CFOP or Roux?

After a full beginner solve feels obvious. CFOP is the common speed path; Roux is the block-building alternative.

What are the F2L, OLL, and PLL libraries for?

They deepen CFOP after the overview: pairing cases, then last-layer orientation and permutation, each with Cube Lab demos.

Can I practise these guides in the browser?

Yes. Every guide links into Cube Lab with the matching Learn or drill mode so you can watch algorithms on a 3D cube.
