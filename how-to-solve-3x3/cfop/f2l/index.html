Before you start

This is the F2L dictionary for CFOP, not a new method. Learn the beginner method first, then the CFOP cross. White stays on the bottom.

Algorithms assume the front-right slot. Mirror them for the other three slots. You do not need all 41 memorised — start with the four basic inserts, then the cases you actually see.

Five ideas (intuitive F2L)

Any case is a variation of pairing. Algorithms come after this feels obvious.

  1. Basic pairing. Corner and edge already joined? Hold the pair over the empty slot and insert.
  2. Corner in the slot. Take the corner out, pair it with the edge on U, put both back.
  3. Edge in the slot. The mirror: free the edge, pair, insert.
  4. Both on U. Use the empty slot as a keyhole. Hide one piece, join them on top, insert.
  5. Split or trapped. Dump both pieces to U, then treat it as a normal U-layer case.

Stuck?

If other slots break, you used L / F on a right-slot algorithm, or you rotated the cube mid-algorithm. Undo, hold FR in front, retry.
