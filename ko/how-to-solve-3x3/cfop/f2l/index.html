F2L 케이스 라이브러리

크로스 다음에, 흰 코너와 짝 엣지를 페어로 묶어 한 번에 넣습니다. 41개 케이스 전부 앞-오른쪽(FR) 슬롯 기준입니다. 필터로 고른 뒤 Cube Lab에서 시연하세요.

시작하기 전에

이 페이지는 CFOP용 F2L 사전이지, 새 해법이 아닙니다. 먼저 입문법을 익히고, CFOP 크로스를 배운 뒤 보세요. 흰 면은 아래에 둡니다.

알고리즘은 앞-오른쪽(FR) 슬롯을 가정합니다. 나머지 세 슬롯은 거울로 적용하세요. 수 기호 전체: 큐브 노테이션 안내.

시연은 케이스 → 해법 순으로 재생됩니다. Cube Lab이 리셋한 뒤 역수를 즉시 적용해 페어를 보여 주고, 알고리즘을 애니메이션으로 돌립니다.

F2L이 필요한 이유

입문법은 흰 코너를 넣고, 그다음 중간 엣지를 넣습니다—같은 조각을 두 번 봅니다. F2L은 코너와 짝 엣지를 하나의 페어로 묶어 함께 삽입합니다. 수가 줄고, 지금 페어가 끝나는 동안 다음 페어를 미리 보는 룩어헤드가 시작됩니다.

첫날에 41개를 다 외울 필요는 없습니다. 직관적 페어링에 알고리즘 몇 개만 더해도 입문의 첫 두 층보다 이미 낫습니다.

다섯 가지 아이디어 (직관적 F2L)

어떤 케이스든 페어링의 변형입니다. 이 느낌이 분명해진 뒤에 알고리즘을 붙이세요. 아래 필터 칩으로 해당 가족을 둘러보세요.

  1. 기본 페어링. 코너와 엣지가 이미 붙었나요? 빈 FR 슬롯 위에 페어를 두고 짧은 R/U 트리거로 넣습니다. 필터: 기본 삽입.
  2. 코너가 슬롯에 있음. 코너를 U로 빼내 엣지와 페어를 만든 뒤 다시 넣습니다. 필터: 코너가 슬롯에 있음.
  3. 엣지가 슬롯에 있음. 거울 버전: 엣지를 풀어 U에서 페어한 뒤 삽입. 필터: 엣지가 슬롯에 있음.
  4. 둘 다 U. 빈 슬롯을 키홀로 씁니다. 한쪽을 숨기고 위에서 붙인 다음 삽입. 필터: 둘 다 U층.
  5. 갈라짐·갇힘. 먼저 둘 다 U로 올린 뒤, 평범한 U층 케이스로 다룹니다. 필터: 갈라짐·갇힘.

인식 습관. 먼저 FR 슬롯을 보세요. 비었나요? U에서 페어를 찾습니다. 차 있나요? 어느 조각이 잘못됐는지 이름 붙인 뒤, 위의 맞는 아이디어를 고르세요.

학습 순서

  1. 기본 삽입 네 가지 (이미 페어가 만들어져 넣을 준비만 된 경우).
  2. 코너가 슬롯에 있는 경우, 그다음 엣지가 슬롯에 있는 경우 — 스크램블 후에 끊임없이 나옵니다.
  3. 둘 다 U에 있고 키홀 셋업이 분명한 경우.
  4. 고급·어색한 케이스는 마지막. 앞 세 그룹이 “헷갈림”이 아니라 “느림”일 때만.

흔한 실수: 알고리즘 중간에 Front를 잘못 잡기; 오른쪽 슬롯 해법에 L이나 F를 써서 이미 맞춘 슬롯을 깨기; 페어를 맞추려고 AUF(U 회전) 대신 큐브 전체를 돌리기.

41개 케이스

연습 경로

  • 기본 삽입만 드릴해서 모든 삽입이 자동이 될 때까지.
  • 코너가 슬롯에 있음과 엣지가 슬롯에 있음을 추가하고, Cube Lab에서 각각 랜덤 10개.
  • 스크램블 → 크로스 → 타이머 없이 F2L. 돌리기 전에 아이디어 이름을 먼저 말하세요.
  • 대부분 찾아보지 않고 풀리면 시간 측정 F2L 드릴로 옮긴 뒤 2-look OLL을 여세요.

막혔을 때

다른 슬롯이 깨지면, 오른쪽 슬롯 알고리즘에 L / F를 썼거나 중간에 큐브를 돌린 것입니다. 되돌린 뒤 FR을 앞에 두고 다시 하세요.

페어가 “거의 맞는데” 안 들어가면, AUF(U 회전)로 코너 색이 FR 센터와 맞을 때까지 돌린 뒤 삽입하세요 — 큐브 전체를 비틀지 마세요.

짧은 CFOP 레시피가 필요하면 3×3 CFOP으로 풀기. 블록이 더 맞으면 Roux.

다음 단계

2-look OLL로 가고, 이어서 2-look PLL. Full OLL/PLL은 4-look 라스트 레이어가 편해진 뒤에. CFOP 전체 흐름은 CFOP 개요로 돌아가세요.

FAQ

F2L 41개 케이스를 전부 외워야 하나요?

아니요. 기본 삽입 네 가지와 자주 나오는 케이스부터 시작하세요. 그다음 코너가 슬롯에 있는 경우, 엣지가 슬롯에 있는 경우를 추가합니다. 고급 케이스는 앞 그룹이 느려질 때 마지막에 익히면 됩니다.

왜 알고리즘이 앞-오른쪽(FR) 슬롯만인가요?

슬롯 하나를 기준으로 두면 목록이 짧아집니다. FL, BR, BL은 같은 아이디어를 거울로 뒤집거나 회전하면 됩니다. 매번 FR을 앞에 두는 습관이 네 세트 알고리즘을 외우는 것보다 인식을 빨리 키웁니다.

언제 OLL을 시작해야 하나요?

일부 케이스가 아직 느리더라도, 페어를 매번 찾아보지 않고 F2L을 끝낼 수 있을 때입니다. 그다음 OLL 라이브러리를 열고 2-look부터 배우세요.

왜 F2L 알고리즘 중간에 첫 두 층이 깨지나요?

많은 삽입이 슬롯을 일부러 열었다가 다시 닫습니다. 큐브를 판단하기 전에 알고리즘 전체를 끝까지 하세요. 알고리즘 후에도 다른 슬롯이 깨져 있으면, 오른쪽 슬롯용 해법에 L이나 F를 썼거나 중간에 큐브를 돌린 것입니다.

알고리즘을 외울까요, 직관적으로 할까요?

기본 페어링은 직관적으로 유지하세요. 자꾸 헤매는 케이스—대개 코너나 엣지가 이미 슬롯에 있는 경우, 어색한 둘 다 U 배치—만 알고리즘을 외우면 됩니다.
