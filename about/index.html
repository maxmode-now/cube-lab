About Cube Lab

A free browser trainer for Rubik’s cubes. Play, learn, scan, and solve — on one page, with no account and no install required.

Last updated 20 August 2026

What it is

Cube Lab runs at cube.maxmode-now.com. It is a static web app: English and Korean, installable as a PWA over HTTPS.

  • Play — 2×2 through 5×5, scramble, timer (WCA-style inspection, ao5 / ao12 / PB).
  • Learn — beginner tracks, 2×2 Ortega, 3×3 CFOP / 4-look last layer, F2L / OLL / PLL libraries, Roux.
  • Solve — beginner steps or a fast search (Kociemba on 3×3). 4×4 and 5×5 reduce to a 3×3 first.
  • Scan — photograph or camera-capture all six faces; confirm and edit before applying. Images stay in the browser.
  • Guides — written recipes with diagrams: how-to-solve.

무엇이냐

Cube Lab은 cube.maxmode-now.com에서 동작하는 정적 웹 앱입니다. 영어·한국어, HTTPS에서 PWA로 설치할 수 있습니다.

  • 플레이 — 2×2–5×5, 섞기, 타이머 (WCA식 인스펙션, ao5 / ao12 / PB).
  • 학습 — 초보자법, 2×2 Ortega, 3×3 CFOP / 4-look 마지막 층, F2L / OLL / PLL, Roux.
  • 풀이 — 초보 단계 또는 빠른 탐색 (3×3은 Kociemba). 4×4·5×5는 먼저 3×3으로 줄입니다.
  • 스캔 — 사진 또는 카메라로 6면을 찍고, 확인·수정한 뒤 적용합니다. 이미지는 브라우저에만 남습니다.
  • 가이드 — 도해가 있는 글 가이드: how-to-solve.
